📈 Market Analysis AI Agent

Autonomous multi-agent system for market research, strategy generation, and backtesting

About This Project

This is an autonomous multi-agent AI system that performs market research, data analysis, strategy generation, backtesting, and iterative optimization using an AutoResearch loop.

🔧 Features

  • Multi-agent architecture for specialized tasks
  • AutoResearch loop for continuous improvement
  • Market research and data collection
  • Strategy generation based on research
  • Backtesting of generated strategies
  • Iterative optimization based on backtest results

🚀 How to Use

The full application with interactive analysis is available through our hosted backend. To use the complete system:

  • Clone this repository
  • Install dependencies: pip install -r requirements.txt
  • Run the Flask application: python web_app.py
  • Access at http://localhost:5000
